# WCAG 2.2 AA manual checklist

Use this list for the human pass after the automated check. Automated checks plus a 1 to 2 hour pass through this list cover roughly 50 to 55 percent of WCAG 2.2 AA. No screen-reader testing is included. Do not mark any row on this list as passed from the automated run. A tick is a person's note for that criterion.

This checklist is not a compliance certificate.

- 1.1.1 Non-text Content (A, partial). Whether each image description says what the image is for.
- 1.2.1 Audio-only and Video-only (Prerecorded) (A, manual). A transcript or description for any audio-only or video-only media.
- 1.2.2 Captions (Prerecorded) (A, partial). Whether captions are present, accurate, and in sync.
- 1.2.3 Audio Description or Media Alternative (Prerecorded) (A, manual). An audio description or text alternative for video.
- 1.2.4 Captions (Live) (AA, manual). Captions on any live video.
- 1.2.5 Audio Description (Prerecorded) (AA, manual). An audio description track for video.
- 1.3.1 Info and Relationships (A, partial). Whether headings, lists, tables, and form groups are marked up as what they look like.
- 1.3.2 Meaningful Sequence (A, manual). Whether the reading order makes sense with styles turned off.
- 1.3.3 Sensory Characteristics (A, manual). Instructions that rely only on shape, colour, size, or position.
- 1.3.4 Orientation (AA, manual). Whether the site works in both portrait and landscape.
- 1.3.5 Identify Input Purpose (AA, partial). Whether fields asking for the customer's own details say what they are for, so a browser can fill them in.
- 1.4.1 Use of Color (A, partial). Information shown only by colour, such as a red field with no message.
- 1.4.2 Audio Control (A, partial). A way to stop sound that plays by itself.
- 1.4.4 Resize Text (AA, partial). Whether the page still works zoomed to 200%.
- 1.4.5 Images of Text (AA, manual). Text shown as a picture instead of real text.
- 1.4.10 Reflow (AA, manual). Whether the page works at 320 pixels wide without scrolling sideways.
- 1.4.11 Non-text Contrast (AA, manual). The contrast of field borders, icons, and focus outlines.
- 1.4.12 Text Spacing (AA, partial). Whether text still fits when a reader widens the spacing.
- 1.4.13 Content on Hover or Focus (AA, manual). Tooltips and pop-ups that can be dismissed and stay while read.
- 2.1.1 Keyboard (A, partial). Whether every control works with the keyboard alone.
- 2.1.2 No Keyboard Trap (A, manual). Whether keyboard focus can always leave a widget.
- 2.1.4 Character Key Shortcuts (A, manual). Single-key shortcuts that can be turned off or changed.
- 2.2.1 Timing Adjustable (A, partial). Time limits, such as a checkout session, that can be extended.
- 2.2.2 Pause, Stop, Hide (A, partial). Moving content, such as a carousel, that can be paused.
- 2.3.1 Three Flashes or Below Threshold (A, manual). Content that flashes more than three times a second.
- 2.4.1 Bypass Blocks (A, partial). A working skip link or landmarks to jump past the menu.
- 2.4.2 Page Titled (A, partial). Whether each page title says what the page is.
- 2.4.3 Focus Order (A, manual). Whether keyboard focus moves in an order that makes sense.
- 2.4.4 Link Purpose (In Context) (A, partial). Whether each link says where it goes, such as no lone "click here".
- 2.4.5 Multiple Ways (AA, manual). More than one way to find a page, such as a menu and a search.
- 2.4.6 Headings and Labels (AA, manual). Whether headings and labels describe what follows them.
- 2.4.7 Focus Visible (AA, manual). A visible outline on whatever has keyboard focus.
- 2.4.11 Focus Not Obscured (Minimum) (AA, partial). Focus hidden by a banner or chat window that only appears after interaction.
- 2.5.1 Pointer Gestures (A, manual). Pinch, swipe, or multi-finger gestures with a single-tap alternative.
- 2.5.2 Pointer Cancellation (A, manual). Actions that happen on release, so a slip can be cancelled.
- 2.5.3 Label in Name (A, manual). Whether a control's spoken name includes the words shown on it.
- 2.5.4 Motion Actuation (A, manual). Shake or tilt actions with an on-screen alternative.
- 2.5.7 Dragging Movements (AA, partial). Whether everything done by dragging, such as a slider or a sortable list, can also be done with single clicks or taps.
- 3.1.1 Language of Page (A, partial). Whether the declared language is the one the page is written in.
- 3.1.2 Language of Parts (AA, partial). Passages in another language marked as such.
- 3.2.1 On Focus (A, manual). Whether focusing a control changes the page by surprise.
- 3.2.2 On Input (A, manual). Whether changing a field changes the page by surprise.
- 3.2.3 Consistent Navigation (AA, manual). Menus in the same order on every page.
- 3.2.4 Consistent Identification (AA, manual). The same thing named the same way on every page.
- 3.2.6 Consistent Help (A, partial). Help such as a phone number, contact page, or chat in the same place on every page that has it.
- 3.3.1 Error Identification (A, manual). Whether a form says which field is wrong, in words.
- 3.3.2 Labels or Instructions (A, partial). Whether fields explain the format they expect.
- 3.3.3 Error Suggestion (AA, manual). Whether an error message says how to fix it.
- 3.3.4 Error Prevention (Legal, Financial, Data) (AA, manual). A chance to review, correct, or cancel an order before it is placed.
- 3.3.7 Redundant Entry (A, partial). Details asked for twice in one process, such as a delivery address typed again for billing with no "same as" option.
- 3.3.8 Accessible Authentication (Minimum) (AA, partial). Puzzles or memory tests at sign-in, and whether a password manager or pasting can fill the password.
- 4.1.2 Name, Role, Value (A, partial). Custom controls, such as dropdowns built from divs, that a screen reader cannot use.
- 4.1.3 Status Messages (AA, manual). Messages such as "Added to cart" announced without moving focus.
